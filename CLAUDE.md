- Never commit or print `private/config.php`, API keys, `private/data/`, or `public/assets/*` (all gitignored).
- Paid APIs (Higgsfield, ElevenLabs, fal.ai): never call them from tests or while fixing finishing/captions. Keep the per-call approval checks and fingerprint duplicate protection.
- Price rule: highest positive advertised price; wording in ads is "Just $14,688".
- Spoken text vs caption text are separate fields; captions use correct spelling and whole-dollar prices. Scripts use whole dollars (`adPrice`). Spoken text spells acronyms/model codes with hyphens (SUV → "S-U-V", XV → "X-V", CR-V → "C-R-V"; `acronymSpeech` in `speechScript`) because voice models read them as words; commas made Bella pause too long; 30-second scripts target 55–60 spoken words.

Render check: see docs/DEPLOY_UBUNTU.md and the test recipe in tests/captions.php comments.
- DealerCenter sync today: the website (mygoldenauto.net) blocks this server via Cloudflare, so the snapshot (vehicles, descriptions, photo URLs) is read from the public website in a browser and fed to `private/dealercenter_sync.php`; the server downloads photos itself from imagescf.dealercenter.net (not blocked). CDN paths are `/W/H/[overlay-folder/]<document>.jpg`; the sync always drops the overlay folder so video references never carry the website's logo/phone overlay. DealerCenter changes reach the website within a few hours. Cars not yet posted online need DealerCenter in Chrome (ZIP fallback). Never store DealerCenter credentials and never put cost/valuation fields in the snapshot. Stored JSON turns 9000.0 into 9000: compare prices by value (`dcSamePrice`).
- Video flow (default, voice=elevenlabs): same four-shot walkaround prompt, but the user first approves an ElevenLabs narration for the car (Narration panel). Its MP3 is sent as Seedance `audio_urls` (promptNative mode 'speech'), and the final render replaces the generated audio with that exact approved MP3, delayed NARRATION_OFFSET (0.5 s), with captions timed from it. Chosen because Seedance re-creates the words and mispronounced San Ramon, Golden Auto, codes and numbers. Spoken text says years and comma numbers as words (`numberSpeech`); `speechWordCount` keeps counting them as written so the tuned 55–60 word budget is unchanged.
- Video flow (voice=native, Seedance voice): Seedance 2.5 `generate_audio` true with `promptNative()` — four wide shots around the whole parked car (front three-quarter, side, rear three-quarter, front from the other side); the entire car is in frame and in focus in every shot and the spokesperson walks around it beside the car, never between camera and car (user feedback after two test renders). She speaks the script word for word (nativeSpeech form: 'dot net', pronunciation guide for San Ramon). Optional config voice_reference_url is sent as Seedance audio_urls for a consistent voice. One paid approval; `goldenNativeBuild` (auto_build.php, via caption_worker) polls Higgsfield for free, then the worker times captions from the video's own speech (`goldenNativeCaptions`) and burns them as white bold on black boxes. Tests: tests/native_voice.php.
- Video flow (voice=narration): Seedance renders a silent walkaround (`generate_audio` false, no spoken script; spokesperson walks the near side talking to camera). Voice = approved ElevenLabs narration. "Build final video" = one paid lip-sync approval with `auto_build`; `private/auto_build.php` (run by caption_worker every minute) polls fal, drafts captions from the narration audio and queues the render.
- Asset sheet = 4 photos in a 2×2 grid: front, side, other side, rear. Photo order differs per car, so when a sync adds a car or replaces its photos, look at its gallery and send `sheet_photos` (1-based positions, in that order); no picks → first four photos. Avoid close-ups with text (labels, stickers).
